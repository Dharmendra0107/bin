Laravel E-Commerce Platform

~40%
Query Time ↓
Live
Production Status
🎯 Problem
NDMEAA Technology needed a production-grade e-commerce platform to manage products, orders, and customers. Existing SQL queries were unoptimised, causing slow admin dashboard loads and poor user experience under moderate traffic.
⚙️ Solution
Rebuilt the backend using Laravel's Eloquent ORM with eager loading and query caching. Introduced REST APIs to decouple frontend (JavaScript/React) from backend, improving maintainability and future scalability.
🧠 Tech Decisions
Chose Laravel over raw PHP for its built-in auth, migrations, and Artisan CLI. MySQL with indexed columns and composite queries replaced multiple N+1 patterns. REST API design allowed a parallel React frontend build without backend blockers.
📈 Outcome
30% overall backend efficiency improvement measured by admin response times. Cart-to-order flow reduced from 6 SQL calls to 2. Deployed to shared Linux hosting via Git + Nginx with zero-downtime deploy script.

Full-Stack Quiz App Platform

2
Role Types (Admin/Student)
JWT
Secured Auth
MERN
Full Stack
🎯 Problem
Softpro India needed an internal quiz platform for assessments. Students needed a clean interface to take timed quizzes; admins needed to create, manage, and analyse quiz results — all in one system with strict access separation.
⚙️ Solution
Built a MERN stack application with role-based JWT authentication. Two completely separate dashboards: student portal for quiz-taking with real-time countdown, and admin panel for CRUD quiz management and performance analytics.
🧠 Tech Decisions
Chose MongoDB for flexible quiz schema (variable question types). React Context API for state management kept the bundle lean without Redux overhead. Express.js middleware chain handles auth, validation, and error responses uniformly.
📈 Outcome
Delivered within the 8-week internship window. Earned "Outstanding Intern" recognition. Admin analytics reduced manual result-checking effort by ~70%. Role-based access prevented any data leakage between student and admin contexts in all test cases.
🛠 Stack
MongoDBExpress.js ReactNode.js JWTREST API Context API
